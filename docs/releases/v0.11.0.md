OpenMic 0.11.0 makes the interface easier to use with a keyboard, screen reader, smaller window or larger text.

## Changes

- Voice settings, routing selectors, presets, soundboard pads, recording controls and shortcut rows adapt to narrower windows and larger text. Focused controls stay visible when you navigate, resize or zoom. Long device, clip and preset names show their full text on hover.
- Keyboard focus follows recording, saving, microphone tests, transcription cancellation, model downloads and updates as their controls change. Moving focus or changing pages while a background task finishes preserves your choice.
- Holding **Enter** or **Space** performs an action once. Release before activating the next control, so a held key cannot start another recording, repeat an update action or reopen a finished editor.
- Soundboard names can be edited with the keyboard. Saving, cancelling or removing a clip returns focus to the appropriate pad or search control. Clip menus scroll to reveal the focused control, and shortcut capture preserves text, selections and volume settings.
- Presets support keyboard saving and deletion through **Shift+F10**. Shortcut capture and clearing keep focus usable, including when global shortcuts are unavailable.
- The strip has clearer focus outlines, keyboard navigation and screen reader descriptions. Hover details stay within the screen without taking keyboard focus, and sidebar navigation scrolls above the processing and mute controls when space is tight.
- Release notes support keyboard scrolling and return focus when closed. Settings recovery, links and folder buttons also preserve focus and avoid repeated actions while a key is held.
- Recording filenames handle additional Windows reserved device names, including names with superscript digits and spaces before an extension.

## Download and upgrade

Click the version number (or wait for the daily check), then **Update** and **Restart to update**. Or download `openmic-v0.11.0-windows-x64.exe` and run it in place of the previous version. Your soundboard and settings carry over.

Requires Windows 10 or 11 (x64) and the [Microsoft Visual C++ v14 Redistributable (x64)](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). The `.sha256` and `.sig` assets hold the executable's checksum and signature.
