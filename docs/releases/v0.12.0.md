OpenMic 0.12.0 runs natively on Linux, with a PulseAudio/PipeWire virtual microphone that works in Discord, OBS and browsers.

## Changes

- Linux support: OpenMic creates **OpenMic Virtual Cable** and **OpenMic Microphone** with `pactl` while it runs, then removes them on exit. It works with PulseAudio and PipeWire's `pipewire-pulse`.
- Linux remembers the previous default microphone, switches to **OpenMic Microphone** while processing, and restores the old default on stop or exit.
- Linux uses 10 ms PulseAudio buffers instead of the server's large default, keeping capture and playback responsive.
- **Computer audio** recording on Linux captures the selected or default output's monitor source.
- **Start on login** writes an XDG autostart entry, and a single-instance lock stops a second copy from disturbing the running one.
- Linux limitations: there is no notification-area tray (closing the window quits), no in-app updater, and dictation shows the transcript to copy instead of typing it into another app. Global hotkeys work on X11, not Wayland.

## Download and upgrade

Windows: click the version number (or wait for the daily check), then **Update** and **Restart to update**. Or download `openmic-v0.12.0-windows-x64.exe` and run it in place of the previous version.

Linux: download `openmic-v0.12.0-linux-x86_64.tar.gz`, extract it, and run `./openmic`. PulseAudio, or PipeWire with `pipewire-pulse`, and the `pactl` command are required.

Your soundboard and settings carry over. The Windows `.sha256` and `.sig` assets hold the executable's checksum and signature.
