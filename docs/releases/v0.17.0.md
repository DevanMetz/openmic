OpenMic 0.17.0 introduces a studio-grade UI overhaul and faster, leaner real-time audio processing.

## Interface & Layout
- Redesigned Dark and Light themes with layered studio surfaces, crisp vector sidebar icons, an elevated live audio dock with segmented level ticks, refined scope wells with dB gridlines, aligned hotkey keycaps, and cleaner badges.
- Removed visual scroll bars across the app while keeping smooth wheel, trackpad, and keyboard scrolling.
- Moved Soundboard **Playback** controls to the top with a fixed height so **Sound Pads** expand to fill the rest of the window and scale cleanly across wider screens.

## Performance & Size
- Enabled runtime-dispatched x86 SIMD (`SSE4.1` and `AVX2`/`FMA`) for vendored RNNoise and trimmed unused audio codec crates for a smaller standalone binary.
- Replaced per-frame scope rectangle bursts with single-mesh GPU fills and added adaptive repaint cadence for lower idle GPU/CPU usage.
- Switched the streaming resampler to a zero-move ring buffer, skipped DeepFilterNet inference while muted or bypassed, upgraded clip resampling to cubic Hermite interpolation, and added LRU eviction for the soundboard clip cache.
