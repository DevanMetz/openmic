OpenMic 0.13.0 brings the Linux build in line with Windows: a notification-area icon, in-app updates, Wayland global shortcuts and typed dictation on X11.

## Linux

- OpenMic keeps running in the notification area when the window closes, with the same menu as Windows. Without a tray host, closing the window still quits.
- In-app updates: click the version number, then **Update** and **Restart to update**. The archive's checksum and signature are checked before it is installed.
- Global shortcuts work on Wayland through the desktop's GlobalShortcuts portal, which asks once to confirm them. X11 keeps its key grab.
- Finished dictation is typed into the focused window on X11. Wayland still shows the transcript to copy.
- Launching OpenMic again shows the running window instead of exiting.
- Links, folders and the releases page open with `xdg-open`.
- The window opens with GLX on X11 (falling back to EGL) and with EGL on Wayland.
- The level strip stays above other windows on X11, and restored windows stay on a connected monitor.

## Audio

- The virtual cable runs at 48 kHz stereo with a short buffer on PulseAudio. A leftover or older 44.1 kHz cable is recreated.
- Audio threads request real-time priority through RealtimeKit.
- **Computer audio** finds monitor sources by device id, so it works with translated device names.
- ALSA's null device is no longer offered or picked as a microphone.

## Fixes

- **Start on login** respects an autostart entry the desktop has turned off, and no longer rewrites it on launch.
- `openmic --help` and `openmic --version` print and exit instead of opening the window.

## Download and upgrade

Windows: click the version number (or wait for the daily check), then **Update** and **Restart to update**. Or download `openmic-v0.13.0-windows-x64.exe` and run it in place of the previous version.

Linux: download `openmic-v0.13.0-linux-x86_64.tar.gz`, extract it, and run `./openmic`. Coming from 0.12.0, this one download is manual; later versions update in the app. PulseAudio, or PipeWire with `pipewire-pulse`, and the `pactl` command are required.

Your soundboard and settings carry over. The `.sha256` and `.sig` assets hold each download's checksum and signature.
